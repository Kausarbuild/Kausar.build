# Kausar.Build — WordPress Theme

A precision-crafted, fully editable, and high-performance WordPress theme for Kausar.Build (`https://kausar.build/`).

## Key Features

1. **Exact Visual Reproduction**:
   - Interactive hanging ID pass with physics simulation on hover/mousemove.
   - Distinctive warm off-white canvas `#FAF9F6` with clean borders and subtle box shadows.
   - Interactive bento grid including personal Spotify player widget, travel snapshots, studio workstation & environment card, and guiding philosophy note.
   - Digital product design archive with 2x2 grid, category badges, and year tags.
   - Numbered service accordions 01-05 with smooth expansion.
   - Testimonials slider with client portrait and quote pagination.
   - Profile verification card with location, experience, and focus alongside ongoing website support retainer.
   - 3-step interactive booking wizard with instant validation and email notifications.

2. **Full WordPress Native Customization**:
   - **Customizer Panels**: Live control of hero bio, ID pass photo, profile details, retainer support, and accent colors.
   - **Custom Post Types**: `portfolio_project`, `studio_service`, `client_testimonial`, `booking_service`.
   - **Extensibility Hook**: `studio_build_after_booking_submit` to connect to Calendly, Cal.com, or Stripe.
   - **Zero Vendor Lock-in**: Clean, modern vanilla JavaScript and CSS with no bloated page builder plugins required.

## Installation

1. In WordPress Admin, navigate to **Appearance → Themes → Add New → Upload Theme**.
2. Select `recreated-wordpress-site.zip` and click **Install Now**.
3. Click **Activate**.
4. Demo projects and consultation booking options are automatically seeded on activation.
